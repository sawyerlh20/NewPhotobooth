# Photobooth – starter project (EK-TM4C123GXL)

This folder layout is a suggestion, not a requirement. You may reorganise,
rename or replace anything here as long as your design is clear.

Search the project for `TODO` to find what is missing.

| Folder     | Contents |
|------------|----------|
| `bsp/`     | Board support: everything about the LaunchPad itself. |
| `drivers/` | One driver per external device (camera, display, printer). |
| `app/`     | Your application logic. |
| `utils/`   | TivaWare helper code (`UARTprintf`). |
| `main.c`   | Entry point. |
